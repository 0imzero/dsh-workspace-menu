# dsh-workspace-menu

把 DSH 主页的工作区和会话管理补齐：双击或右键，就能置顶、重命名、打开资源管理器、归档、分叉、复制、新窗口打开。所有开关都收在设置面板的独立页面里，按需开启。

> **v2.0.0 起仅支持 DSH 0.2.x**（`dsh >= 0.2.1-rc.3`）。0.1.x 请用 v1.2.x。

## 亮点

- **工作区操作**：置顶、重命名、在资源管理器中打开、复制路径、新建会话、从列表移除、删除工作区（含磁盘）
- **会话操作**：置顶、重命名、标记未读/已读、归档、取消归档、分叉、复制会话链接、复制会话标题、在新窗口中打开、打开所在目录、删除会话（含磁盘记录）
- **会话置顶走 Host 权威状态**：与 DSH 内置的「置顶会话」按钮共享同一份 pin 集合，刷新、换浏览器、多端都一致
- **跨平台**：Windows 用资源管理器，macOS 用 Finder，Linux 自动选择 `xdg-open` / `gio` / 常见文件管理器
- **设置独立成页**：设置面板 → 工作区菜单，一页列全 20 个开关，带中英文
- **不动内置源码**：通过 DOM 事件和 React fiber 定位工作区/会话行，不修改 DSH 自带代码
- **删除不依赖外部插件**：会话记录与工作区目录都由本插件自己的宿主路由删除

## 功能

Project 行（双击或右键）：

- 置顶 / 取消置顶
- 重命名
- 在资源管理器中打开
- 复制路径
- 新建会话
- 从工作区列表中移除（保留磁盘）
- 删除工作区（含磁盘，二次确认）

Chat 行（双击或右键）：

- 置顶 / 取消置顶
- 重命名
- 标记未读 / 已读
- 归档会话
- 取消归档（会话已在归档集合时出现）
- 分叉会话
- 复制会话链接
- 复制会话标题
- 在新窗口中打开
- 打开所在目录
- 删除会话（含磁盘记录，二次确认）

设置独立成页：**设置 → 工作区菜单**，可以单独开关每个功能。

## 安装

从 Releases 下载 tgz，然后：

```bash
dsh plugin --profile web add dsh-external-dsh-workspace-menu-2.0.0.tgz
```

本地开发：

```bash
npm install
npm run build
```

## 说明

- “在资源管理器中打开”由 Host 调用系统文件管理器：Windows 用资源管理器，macOS 用 Finder，Linux 自动选择 `xdg-open` / `gio` / 常见文件管理器。
- **工作区**置顶和**未读**状态存在浏览器 localStorage；**会话**置顶由 Host 保存（0.2.x 内置能力），不再存本地。
- 新窗口打开依赖 `?session=<id>` 深链；DSH 0.2.x 本身没有 URL 路由，深链由本插件负责。
- 设置页位于 DSH 设置 → 工作区菜单。
- “删除会话（含磁盘记录）”和“删除工作区（含磁盘）”由本插件的宿主路由完成，不再需要 `@mlgbnb/dsh-archive-manager`。
- 会话记录目录固定在 `$DSH_HOME/sessions/<工作区 slug>/<sessionId>/`，删除只会命中与请求 id 同名的目录。
